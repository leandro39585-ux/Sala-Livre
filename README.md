# SalaLivre

Sistema inteligente de gestão e reserva de salas escolares (Escola Secundária Monserrate).

- Perfis: Professor, Funcionário, Administrador
- Dados fictícios, 100% front-end (um único `index.html`)
- PWA: `manifest.json` + `icon.svg`

## Publicar
- **Vercel / Netlify:** importar o repositório (sem build, pasta raiz).
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.

## Demonstração
Professor reserva a sala A02 → comunica projetor avariado → Funcionário põe em resolução → Administrador vê no mapa, estatísticas e notificações.
